# 课堂同传

将老师的英文实时识别，同步显示英文原文与简短中文翻译，同时使用系统中文语音播报。

核心能力：

- 流式英文原文字幕与同步中文字幕
- 低置信度内容统一标记为 `【未听清】`
- 数字、单位、公式和专业缩写原样保护
- 中文语音播报、暂停、停止和全屏课堂模式
- 浏览器本机翻译优先，并提供在线翻译备用通道

实时稳定性：置信度缺失时保留已识别文字；重复的最终识别结果只记录一次；识别长时间无结果时自动重连，翻译请求设有超时，避免后续字幕一直排队。

运行环境：实时语音识别依赖浏览器的 Web Speech API 和麦克风权限。建议在最新版 Chrome 或 Edge 中使用正式 HTTPS 站点。
